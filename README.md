# VeriGuard AI

VeriGuard AI is an intelligent verification, anomaly detection, and fraud prevention system.

## Project Structure

```
veriguard-ai/
│
├── backend/       # API services and core business logic
├── frontend/      # User interface and dashboard
├── ml/            # Machine learning training, pipelines, and experiments
├── data/          # Datasets, raw inputs, and processed data
├── models/        # Trained model checkpoints and serialized artifacts
├── tests/         # Unit, integration, and performance tests
└── docs/          # Architecture diagrams, specifications, and documentation
```

## Quick Start

### 1. Environment Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. Install Dependencies

```powershell
pip install -r requirements.txt
```
